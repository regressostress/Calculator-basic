## Calculator-basic
Я написал базовый калькулятор!

Он нужен для того чтобы выполнять математические выражение (сложение, вычитание, умножение и деление)!

## Принцип работы:
Принцип работы заключается в том, чтобы мы вводили первое число, дальше знак который нам нужен, а далее второе число и после этого выдается ответ!
Также он проверяет деление на 0, если мы разделим число на 0, то код выдаст ошибку и он начнется заново!

## Как запустить?
1. Скачиваем файл.
2. Открываем Калькулятор.csproj с помощью Visual Studio
3. Нажимаем ctrl f5 и запуститься консольное окно
4. Пользуемся!
