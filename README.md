# Calculator-basic
Я написал базовый калькулятор!

Он нужен для того чтобы выполнять математические выражение (сложение, вычитание, умножение и деление)!

Принцип работы заключается в том, чтобы мы вводили первое число, дальше знак который на нужен, а далее второе число и после этого выдается ответ!
Также он проверяет деление на 0, если мы разделим число на 0, то код выдаст ошибку и он начнется заново!
